During my Erasmus+ internship at Go Project in Italy, I built a website for AMFI. It replaces paper internship forms with online forms.

## How it works

- **AMFI** adds teachers and students and fills in the main information.
- **The student** writes a weekly log of the internship.
- **The company tutor** writes comments and the final assessment.

## Tools

- Python and Django
- HTML and CSS
- Git and GitHub

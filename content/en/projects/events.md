During my Erasmus+ internship at Go Project in Italy, I built a meetup website for AMFI International. Erasmus students use it to find events in their city and meet new people.

## How it works

- **Students** create events and join events made by other students.
- **Search** helps to find an event by keyword, city, date, type and size.
- **An AMFI admin** checks every event before other students can see it.

## Tools

- Python and Django
- Tailwind CSS and daisyUI
- Docker and Dokku for deployment
- Git and GitHub
